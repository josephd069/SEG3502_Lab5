Formulaire d’enregistrement d’un employé

Remplissez les champs ci-dessous pour enregistrer un employé dans Firestore.

Le nom de l’employé est obligatoire.
La date de naissance est obligatoire.
La ville de travail est obligatoire.
Le salaire est obligatoire.
Le genre doit être M, F ou X.
Le format de l’adresse courriel est invalide.
